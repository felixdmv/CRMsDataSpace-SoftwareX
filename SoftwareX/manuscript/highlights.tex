\begin{highlights}
    \item Generic, domain-agnostic NLU-Solr software architecture integrating conversational LLM parsing with Apache Solr spatial search and Leaflet GIS visual synchronization.
    \item Synchronized map-and-chat web application delivering real-time cartographic feedback via glowing pulse markers and interactive active filter badges.
    \item Dual-variant NLU pipeline combining Few-Shot domain exemplars with strict OpenAPI JSON Schema validation to eliminate database schema hallucinations.
    \item On-premises local GPU deployment supporting open-weight LLMs (Llama 3.2, Qwen 2.5, Phi-3, DeepSeek) on private NVIDIA A100 infrastructure for complete European data sovereignty.
    \item Real-world validation and deployment as the conversational demonstrator for the European research project \textbf{CRMsDataSpace} (Grant Agreement No.~101216677).
    \item Zero-setup standalone mock execution mode with a synthetic 100-site dataset, guaranteeing immediate reviewer reproducibility without API key dependencies.
\end{highlights}
